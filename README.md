# ВМуткоин Обменник — Minecraft 26.2 / Fabric

Специальный блок обмена: **четыре случайных ресурса → один предмет `vmtrade:vmcoin`** за нажатие.
Предмет `vmtrade:vmcoin` предоставляет мод **AVECOINS** (`avecoins`) из проекта [market-full1](https://github.com/PuzzleChannel/market-full1); зависимость от `vmtrade` не нужна.

## Установка

1. Удали предыдущий JAR `vmexchange` из папки `mods`.
2. Установи собранный `vmcoin-exchange-1.0.0.jar` на сервер и клиентам.
3. Нужны Minecraft **26.2**, Fabric Loader **0.19.5+**, Fabric API для **26.2** и **AVECOINS**.
4. На сервере обязателен **LuckPerms 5.5 или новее**. Клиентам LuckPerms устанавливать не требуется.

Блок находится в творческой вкладке функциональных блоков:

```
/give @s vmexchange:exchange
```

Рецепта крафта нет. Обменник не привязывается к конкретному блоку или базе: набор для игрока автоматически определяется его группой LuckPerms.

## Страны и доступ

Поддерживаются три страновые группы LuckPerms:

| Страна | LuckPerms ID |
| --- | --- |
| Европа | `europe` |
| Африка | `africa` |
| Азия | `avstralia` |

Все размещённые обменники работают одинаково. Когда игрок открывает любой обменник, сервер проверяет его основную группу LuckPerms; если она не одна из поддерживаемых, проверяются унаследованные группы. Основная группа имеет приоритет.

Игрок без `europe`, `africa` или `avstralia` не может открыть обменник и не может отправить запрос на обмен. При наведении на блок под прицелом отображается красное сообщение **«Вы не можете использовать это.»** Проверка доступа выполняется сервером; клиентское сообщение не является заменой серверной проверки.

Если игрок меняет страновую группу, открытое меню закрывается, а все внесённые предметы возвращаются в его инвентарь. Установить или снять привязку группы у блока больше нельзя — команды `bindgroup`, `unbindgroup` и `groupinfo` удалены.

## Отдельные материалы для каждой страны

Каждая страна получает собственный случайный набор из четырёх материалов:
- первые три ячейки — обычные ресурсы Верхнего мира;
- четвёртая ячейка — специальный ресурс из отдельного пула.

При еженедельном сбросе наборы Европы, Африки и Азии генерируются независимо и сохраняются в данных мира. Наборы трёх стран не повторяются между собой. Один и тот же набор видят все игроки соответствующей страны и все обменники.

Наборы хранятся в `SavedData` мира отдельно от прогресса игрока. При обновлении со старой версии недельный прогресс игроков сохраняется; страновые наборы генерируются при первой загрузке новой версии. Старые привязки блоков больше не используются.

## Обмен

Открой обменник правой кнопкой мыши. В четырёх ячейках показаны материалы именно твоей страны; под каждой ячейкой — внесено / требуется. Внеси все четыре вида и нажми **Обменять**.

Одно нажатие списывает текущую цену **из каждой ячейки** и выдаёт **ровно один ВМуткоин**. Ячейка монеты серая, пока не внесено нужное количество всех четырёх ресурсов; затем подсвечивается золотом.

Shift+клик переносит подходящий ресурс в свою ячейку. Лишние ресурсы можно забрать. При закрытии окна предметы возвращаются в инвентарь; при нехватке места они выпадают рядом с игроком.

Обменные ячейки принимают до 64 предметов, даже если обычный стак предмета меньше. Например, несколько стаков эндер-жемчуга можно объединить для дорогих ступеней. Возвращаемые предметы разделяются на обычные стаки.

Кнопка поддерживает мышь и клавиатуру. Во время ожидания ответа сервера повторное нажатие временно отключено. Успех сопровождается звуком торговли и сообщением. Если не хватает ресурсов или места, кнопка неактивна. Сервер повторно проверяет содержимое ячеек, права, расстояние, недельный лимит и наличие места в инвентаре.

## Недельная экономика

Недельный лимит — **25 ВМуткоинов на игрока**. Учёт лимита и ступени цены общие для игрока, даже если он меняет страновую группу.

| ВМуткоин за неделю | Цена каждого из четырёх ресурсов |
| --- | ---: |
| 1–5 | 1 |
| 6–10 | 5 |
| 11–15 | 10 |
| 16–20 | 15 |
| 21–24 | 20 |
| 25 | 25 |

Сброс по умолчанию — понедельник 00:00 в часовом поясе сервера. Сервер проверяет границу недели раз в секунду и перед самим обменом. Если сервер был выключен, новая неделя определяется при следующем запуске.

Пулы материалов, лимиты, ступени цен и расписание сброса настраиваются в `config/vmexchange.json`.

## Защита блока

- Игроки в Survival и Adventure не могут разрушить обменник; разрушение разрешено только в Creative.
- Поршни и липкие поршни не перемещают блок.
- У блока повышенная устойчивость к взрывам.
- Игрок может использовать обменник только находясь в радиусе 8 блоков. При смене измерения, отходе от блока или смене страновой группы открытое меню закрывается, а предметы возвращаются.

## Команды администратора

Все команды требуют прав администратора:

```
/vmexchange info
/vmexchange setmaterial <europe|africa|avstralia> <1–4> <item_id>
/vmexchange setmaterials <europe|africa|avstralia> <item1> <item2> <item3> <item4>
/vmexchange randomize
/vmexchange limit <amount>
/vmexchange price <tier> <price>
/vmexchange tier <tier> <limit>
/vmexchange resetweek
/vmexchange resetplayer <player>
/vmexchange player <player>
/vmexchange reload
```

`info` показывает текущие четыре материала каждой страны. `setmaterial` и `setmaterials` изменяют только набор указанной страны без сброса недельного прогресса. Чтобы вернуть случайные наборы всем странам, используй `randomize`. Команды `randomize` и `resetweek` сбрасывают недельный прогресс всех игроков.

## Сборка

Требуется **JDK 25**. Windows: `gradlew.bat build`; Linux/macOS: `./gradlew build`.
Готовые JAR находятся в `build/libs`; `-sources.jar` устанавливать не нужно. Задача `check` запускает регрессионные проверки, а GitHub Actions публикует готовый JAR как артефакт сборки.
