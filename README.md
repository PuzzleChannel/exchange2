# Обменник ВКоинов — Minecraft 26.2 / Fabric

Четыре заданных ресурса → **один предмет `vmtrade:vmcoin`** за нажатие.
Монету выдаёт сервер после проверки всех ресурсов, цены, недельного лимита, места в инвентаре и прав доступа.
Предмет `vmtrade:vmcoin` предоставляет мод `avecoins` из проекта `market-full1`; зависимость от `vmtrade` больше не нужна.

## Установка

1. Закрой Minecraft / сервер.
2. Удали предыдущий JAR **vmexchange** из папки `mods`, чтобы не оставить две версии.
3. Скопируй `vmcoin-exchange-1.0.0.jar` из сборки в папку `mods` **на сервере и у игроков**.
4. Нужны Minecraft **26.2**, Fabric Loader **0.19.5+**, Fabric API для **26.2** и мод **AVECOINS** (`avecoins`) из [market-full1](https://github.com/PuzzleChannel/market-full1). Мод `vmtrade` не требуется.
5. Для ограничения по странам на сервере нужен **LuckPerms 5.5 или новее**. Клиентам LuckPerms устанавливать не требуется.

Блок находится в творческой вкладке функциональных блоков. Можно выдать его:

```
/give @s vmexchange:exchange
```

Рецепт крафта не добавлен: способ доступа к обменнику остаётся под контролем сервера.

## Привязка каждого обменника к группе LuckPerms

Каждый размещённый блок привязывается к отдельной группе LuckPerms. Например, обменник на базе Европы можно закрепить за группой `europe`, а обменник Африки — за группой `africa`. Группы должны уже существовать в LuckPerms.

1. Администратор ставит блок на нужной базе.
2. Наводит прицел на сам блок с расстояния не более 8 блоков.
3. Выполняет команду, указав группу:
   ```
   /vmexchange bindgroup europe
   ```
4. Проверяет привязку:
   ```
   /vmexchange groupinfo
   ```

Команда `/vmexchange unbindgroup` снимает привязку, после чего обменник закрывается для всех, пока ему не назначат новую группу. Эти команды требуют права администратора.

Доступ разрешается, если основная группа игрока или унаследованные группы LuckPerms совпадают с группой, назначенной конкретному блоку. Если LuckPerms отсутствует, группа не найдена или обменник не настроен, доступ закрыт. Привязки сохраняются в данных мира и различаются по измерению и координатам блока.

**Открытое меню каждый серверный тик перепроверяет:** блок всё ещё должен существовать на прежнем месте, игрок должен находиться в том же измерении не дальше 8 блоков и сохранять членство в нужной группе. Проверка выполняется повторно и непосредственно перед оплатой. Если блок ломается, игрок уходит, меняет измерение или теряет требуемую группу, окно закрывается. Внесённые ресурсы возвращаются игроку; при нехватке места стандартная логика инвентаря Minecraft может выбросить их рядом с ним.

## Обмен

Открой блок правой кнопкой мыши. В четырёх ячейках показаны требуемые ресурсы;
под каждой — внесено / требуется. Внеси все четыре вида и нажми **Обменять**.
Ячейка монеты серая, пока не внесено нужное количество всех четырёх ресурсов; затем подсвечивается золотом.
Одно нажатие списывает текущую цену **из каждой ячейки** и выдаёт **ровно один ВКоин**.
Shift+клик переносит подходящий ресурс в его ячейку. Лишние ресурсы можно забрать;
при закрытии окна они возвращаются в инвентарь, а при нехватке места выпадают у игрока.
Обменные ячейки принимают до 64 предметов, даже если обычный стак ресурса меньше:
например, несколько стаков эндер-жемчуга можно объединить для цены 20 или 25.
Возвращаемые предметы разделяются на обычные стаки.

Кнопка поддерживает мышь и клавиатуру. Во время ожидания ответа сервера повторное
нажатие временно отключено. Успех сопровождается звуком торговли и сообщением.
Наведи курсор на пустую ячейку, монету, кнопку или шкалу лимита — появится подсказка.
Если не хватает ресурсов или места, кнопка неактивна. Проверка на сервере обязательна,
даже если клиент отправит запрос самостоятельно.

## Сохранённые правила

Недельный лимит по умолчанию — **25 ВКоинов на игрока**.

| ВКоин за неделю | Цена каждого из четырёх ресурсов |
| --- | --- |
| 1–5 | 1 |
| 6–10 | 5 |
| 11–15 | 10 |
| 16–20 | 15 |
| 21–24 | 20 |
| 25 | 25 |

Первые три ресурса выбираются из обычного пула верхнего мира;
четвёртый — из специального пула (эндер-жемчуг / разрешённые руды).
Настройки пулов, ступеней, лимита и расписания — в `config/vmexchange.json`.
Сброс по умолчанию — понедельник 00:00 **в часовом поясе сервера**.
Сервер проверяет границу недели раз в секунду и перед самим обменом.
Если сервер был выключен, новая неделя определяется при следующем запуске.
Изменение материалов не уничтожает уже внесённые предметы: их можно забрать.

## Команды администратора

Все команды требуют прав администратора:

```
/vmexchange info
/vmexchange bindgroup <group>
/vmexchange unbindgroup
/vmexchange groupinfo
/vmexchange setmaterial <1–4> <item_id>
/vmexchange setmaterials <item1> <item2> <item3> <item4>
/vmexchange randomize
/vmexchange limit <amount>
/vmexchange price <tier> <price>
/vmexchange tier <tier> <limit>
/vmexchange resetweek
/vmexchange resetplayer <player>
/vmexchange player <player>
/vmexchange reload
```

`randomize` и `resetweek` сбрасывают недельный прогресс всех игроков.
`setmaterial` / `setmaterials` меняют набор без сброса прогресса.
Открытые окна обновляются после изменения материалов, курса, лимита или перезагрузки конфигурации.
Цена должна помещаться в одну обменную ячейку: максимум 64 предмета каждого вида.

## Сборка исходников

Папка корня репозитория — полноценный Gradle-проект. Требуется **JDK 25**, доступ к интернету
для загрузки Gradle / Minecraft / Fabric и установленный `vmtrade` для проверки в игре.

Windows: `gradlew.bat build`.
Командная строка: `gradlew.bat build` (Windows) / `./gradlew build` (Linux/macOS).
Готовые JAR: `build/libs`. `-sources.jar` — исходники, его не нужно класть в `mods`.
Сборка включает запуск `exchangeRegression` — регрессионные проверки обмена.
GitHub Actions также собирает JAR и публикует артефакт на 30 дней после успешной проверки.

Автоматические проверки покрывают правила оплаты, цены всех 25 ВКоинов, границу недели,
размеры интерфейса и фактическое внесение нескольких стаков эндер-жемчуга в контейнер.
Проверка непосредственно в игре с вашим `vmtrade` всё равно нужна после установки на сервер.
